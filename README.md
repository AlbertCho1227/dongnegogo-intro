# 동네고고 (Dongnegogo)

우리 동네 문화·스포츠·교육 프로그램을 지도와 목록으로 안내하는 모바일 서비스입니다.

---

## 서비스 목적

공공기관(문화센터, 주민센터, 복지관, 공공체육시설 등)이 운영하는
교육·문화·예술·체육 프로그램을 지도 기반으로 탐색하고 접수 일정을 안내합니다.

## 공유누리 API 활용

공유누리 공공개방자원 API를 통해 아래 정보를 사용자에게 제공합니다.

| 항목 | 활용 방법 |
|------|-----------|
| 시설명 · 운영기관 | 프로그램 카드 및 상세 화면에 표시 |
| 주소 | 지도 핀 위치 및 길 안내 |
| 이용 시간 | 시설 운영 시간 안내 |
| 이용료 | 유료·무료 표시 |
| 예약 페이지 URL | 신청 페이지 외부 링크 |

## 개인정보

- 예약자·회원·결제 정보를 수집하지 않음
- 사용자 설정은 기기 내부에만 저장

## 서비스 현황

- 플랫폼: iOS
- 상태: 개발 중
- 데이터 출처: 공유누리, 서울 열린데이터광장, 공공데이터포털
