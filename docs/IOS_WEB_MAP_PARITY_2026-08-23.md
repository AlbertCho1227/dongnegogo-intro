# iOS ↔ 웹 지도 기능 비교 요약

검증일: 2026-08-23
기준: iOS 프로젝트 52개 Swift 파일(약 47,847줄) 읽기 전수 확인, iPhone 17 Pro / iOS 26.5 시뮬레이터 시나리오 확인, 웹 데스크톱·390×844 반응형 브라우저 확인

## 결론

- 지도 탐색 핵심 흐름 구현률: **약 82%**
- 계정·알림·가족 공유를 포함한 iOS 전체 서비스 구현률: **약 66%**
- 이번 변경은 Supabase의 공개 조회와 기존 읽기 전용 RPC만 사용했다. DB·스키마·Auth 설정·사용자 데이터는 변경하지 않았다.
- “100% 동일”은 아직 아니다. 웹 Auth 리다이렉트 승인, 사용자 데이터 쓰기 정책, 브라우저 푸시 알림, 실제 경로·로드뷰 구현이 남아 있다.

## 실제 확인한 반응 시나리오

1. iOS 지도, 찾기, 오픈런, 전체 필터, 같은 장소 프로그램 시트 화면과 반응을 시뮬레이터에서 확인했다.
2. 웹에서 같은 장소 9개 마커를 눌러 `1 / 9`가 즉시 나오고 다음 버튼으로 다른 프로그램 `2 / 9`가 표시되는 것을 확인했다.
3. 교육+무료 필터 적용 시 현재 지도 결과가 77곳에서 6곳으로 즉시 바뀌는 것을 확인했다.
4. `가까운 무료 수영 강좌` 검색에서 수영·무료·5km 조건과 0곳 결과, 조건 완화 버튼을 확인했다.
5. 무더위쉼터 119곳과 냉방·주소·거리·공식 출처 상세를 확인했다.
6. 목적지 100m 주변 가게 34곳, 300m 164곳과 음식점·카페·패스트푸드·편의점 분류를 확인했다.
7. 2026년 8월에서 7월로 이동하고 7월 12일 접수 일정이 표시되는 것을 확인했다.
8. 390×844 모바일 화면에서 지도·찾기·오픈런·찜·내정보와 내 위치·주변·일정·가족·보관함 도구가 유지되는 것을 확인했다.
9. 축척을 넓혀 성북구 641개, 종로구 746개 등 지역 군집으로 전환되는 것을 확인했다.

## 100% 동등 구현에 필요한 승인·선행 조건

1. 웹 Supabase Auth 리다이렉트 URL 등록과 웹 로그인 공개 승인
2. 찜·알림·가족·최근 본·리뷰를 Supabase에 쓰는 권한과 RLS 계약 승인
3. 브라우저 푸시 알림용 서비스 워커·구독 저장·발송 작업 승인
4. Kakao Roadview 및 실제 도보/대중교통/차량 경로선의 웹 구현 방식 확정
5. 계정·리뷰·가족 공유까지 포함한 테스트 계정 제공 및 다기기 인수 테스트
